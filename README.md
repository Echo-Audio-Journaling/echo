# Echo - Audio Journaling Application

A sophisticated Flutter cross-platform application for audio-based journaling and memory recording with intelligent transcription and multi-media support.

## Features

### Core Functionality
- **Audio Journaling**: Record voice memos with automatic speech-to-text transcription using Google Cloud Speech API
- **Multi-Media Support**: Create entries with audio, images, and videos
- **Calendar Organization**: Interactive calendar widget to view and organize entries by date
- **Intelligent Search**: Full-text search across all journal entries with quick preview
- **Smart Prompts**: Randomized journaling prompts across 7 categories (Self-Reflection, Gratitude, Challenges, Creativity, Relationships, Future Planning, Mindfulness)
- **User Profiles**: Google Sign-In authentication with customizable profiles
